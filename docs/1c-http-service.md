# HTTP-сервис 1С: контракт

Сервис живёт в расширении конфигурации УНФ. Базовый адрес и учётные данные приходят из `.env` (`UNF_BASE_URL`, `UNF_USER`, `UNF_PASSWORD`). Авторизация — Basic, пользователь 1С с правами только на чтение. Все ответы — JSON в UTF-8.

Это проектный контракт: изменения на стороне 1С отражаются в этом файле в том же коммите, что и код сервиса.

## GET /metadata

Возвращает описание объектов, доступных для запросов: справочники, документы, перечисления, регистры сведений, накопления, бухгалтерии и расчёта. Для учебной УНФ 3.0.13 это 3504 объекта, около 11 МБ, ответ за 3 с.

```json
{
  "objects": [
    {
      "name": "РегистрНакопления.Продажи",
      "synonym": "Продажи",
      "type": "РегистрНакопления",
      "register_kind": "Обороты",
      "virtual_tables": ["Обороты"],
      "fields": [
        {"name": "Номенклатура", "synonym": "Номенклатура", "role": "Измерение", "type": "Справочник.Номенклатура"},
        {"name": "Сумма", "synonym": "Сумма", "role": "Ресурс", "type": "Число"}
      ]
    },
    {
      "name": "Документ.РасходнаяНакладная",
      "synonym": "Расходная накладная",
      "type": "Документ",
      "fields": [...],
      "tables": [{"name": "Документ.РасходнаяНакладная.Запасы", "synonym": "Запасы", "fields": [...]}],
      "movements": ["РегистрНакопления.Продажи", "..."]
    },
    {
      "name": "Перечисление.ТипыСтруктурныхЕдиниц",
      "synonym": "Типы структурных единиц",
      "type": "Перечисление",
      "values": [{"name": "Розница", "synonym": "Розничный склад"}]
    }
  ]
}
```

- `role` поля: `СтандартныйРеквизит`, `Измерение`, `Ресурс`, `Реквизит`.
- `type` поля: `Число`, `Строка`, `Дата`, `Булево`, полное имя объекта для ссылок (`Справочник.Номенклатура`), несколько типов через запятую; больше пяти типов — `Составной`.
- `tables` (справочники и документы) — табличные части; имя сразу в том виде, в каком пишется в запросе.
- `movements` (документы) — регистры, в которые документ пишет при проведении.
- `register_kind` — только у регистров накопления: `Остатки` или `Обороты`. `virtual_tables` — у всех регистров; у непериодических регистров сведений и регистров расчёта пустой.

Реальные имена объектов и полей — те, что вернёт база.

## POST /query

Запрос:

```json
{
  "text": "ВЫБРАТЬ ПЕРВЫЕ 1000 ...",
  "params": {
    "НачалоПериода": {"type": "date", "value": "2026-11-12T00:00:00"},
    "Склад": {"type": "ref", "catalog": "Справочник.СтруктурныеЕдиницы", "id": "<GUID>"},
    "Порог": {"type": "number", "value": 10000}
  }
}
```

Типы параметров: `date` — строка ISO 8601; `ref` — ссылка по полному имени объекта и GUID (для перечисления `id` — имя значения); `number`, `string`, `boolean` — значение передаётся как есть.

Успех:

```json
{"ok": true, "columns": ["Склад", "Сумма"], "rows": [["Магазин на Партизанской", 84300]], "truncated": false}
```

Ссылочные значения в строках возвращаются представлением (строкой). Даты — ISO 8601.

Ошибка (синтаксис, неизвестное поле, превышено время):

```json
{"ok": false, "error": "текст ошибки 1С"}
```

Ограничения на стороне 1С: не более 1000 строк. Пользователь сервиса не имеет прав на данные, запрос выполняется в привилегированном режиме: язык запросов 1С не изменяет данные, а модуль ничего, кроме запроса, не выполняет. Ограничить время выполнения в файловой базе нельзя, поэтому от тяжёлых запросов защищает `ПЕРВЫЕ N` из валидатора.

Модуль сервиса — `1c/bot_service.bsl`, корневой URL `bot`, полный адрес — `http://<сервер>/unf/hs/bot/query`. Повторное использование сеансов — «Не использовать»: учебная версия платформы ограничивает число подключений, а пул сеансов Apache их не отпускает. По той же причине клиент отправляет в 1С не больше одного запроса одновременно. Учебная лицензия допускает только пустые пароли.

## POST /lookup

Поиск элементов справочника по подстроке наименования.

Запрос: `{"catalog": "Справочник.СтруктурныеЕдиницы", "text": "Партизанская"}`

Ответ: `{"ok": true, "items": [{"id": "<GUID>", "name": "Магазин на Партизанской"}]}` — не более 10 элементов, по алфавиту, без помеченных на удаление. Регистр не важен, служебные символы шаблона (`%`, `_`, `[`) ищутся как обычные. `id` подставляется в параметр `ref` запроса `/query`.

Имя справочника проверяется по метаданным: не справочник — `{"ok": false, "error": "Справочник не найден: ..."}`.

## Установка в конфигураторе

Модули из `1c/` подключаются вручную: в расширении конфигурации создаётся HTTP-сервис с указанными выше шаблонами URL и методами, код обработчиков вставляется из `1c/bot_service.bsl`. Проверка каждого метода — запрос из Postman или curl, ожидаемые ответы приведены в описаниях методов.
