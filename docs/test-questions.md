# Тестовый набор вопросов

31 вопрос руководителя с эталонными запросами по восьми разделам. Набор служит трём целям: примеры для промпта генератора, автотест точности, сценарий видео-демонстрации.

Каждый эталон выполнен через `/query` на демо-базе (учебная УНФ 3.0.13), ожидаемый результат — его ответ. Вопросы 1, 10, 13, 14, 18, 22, 29 дополнительно сверены запросом к таблице движений регистра, без виртуальных таблиц: цифры совпадают.

Данные демо-базы — с января 2021 по апрель 2022, поэтому периоды в вопросах берутся оттуда.

На каждый раздел — общий показатель, показатель с отбором по справочнику, сравнение периодов или рейтинг («топ-5»). Значение справочника из вопроса подставляется параметром-ссылкой: GUID находит `/lookup`.

## Что учесть генератору

- Обороты за период — виртуальная таблица `Обороты(&Начало, &Конец, Периодичность, Условие)`, ресурсы в ней с суффиксом `Оборот` (`СуммаОборот`).
- Остатки на дату — `Остатки(&Дата, Условие)`, ресурсы с суффиксом `Остаток`. Таблица не включает движения в саму дату: «на конец 2021» — это `&Дата` = 01.01.2022 00:00:00.
- Отбор по измерениям — в условии виртуальной таблицы, а не в `ГДЕ`.
- Начисления и удержания лежат в одном регистре; ФОТ — только тип «Начисление».
- В расчётах с контрагентами тип «Долг» и тип «Аванс» имеют разный смысл; задолженность — только «Долг».
