# Архитектура

## Генератор запросов

Каталог метаданных УНФ содержит сотни объектов и целиком в промпт не помещается, поэтому генерация идёт в два шага.

### Шаг 1. Выбор таблиц

Вход: вопрос пользователя и короткий каталог — для каждого объекта полное имя и синоним (`РегистрНакопления.Продажи — Продажи`).
Выход: JSON со списком из 3–5 имён объектов и списком упомянутых значений справочников (`{"catalog": "...", "text": "Партизанская"}`).

Готово, когда для каждого вопроса из `docs/test-questions.md` в выбранный список попадают все таблицы эталонного запроса.

### Шаг 2. Поиск значений справочников

Модель не знает элементы справочников. Для каждого упомянутого значения клиент 1С вызывает метод поиска и получает кандидатов. Один кандидат — подставляется в запрос как параметр. Несколько — бот переспрашивает пользователя списком. Ни одного — бот сообщает, что значение не найдено.

### Шаг 3. Генерация запроса

Вход: вопрос, подробная схема выбранных таблиц (измерения, ресурсы, реквизиты с типами, доступные виртуальные таблицы регистров), найденные значения, текущие дата и часовой пояс, 3–5 примеров «вопрос → запрос» из тестового набора.
Выход: JSON `{"query": "...", "params": {...}}`. Даты и ссылки передаются параметрами (`&НачалоПериода`), в текст запроса значения не вшиваются.

### Шаг 4. Валидатор

Запрос уходит в 1С, когда выполнены все условия:

- это один пакет, каждый оператор начинается с `ВЫБРАТЬ`;
- все таблицы после `ИЗ` и `СОЕДИНЕНИЕ` есть в каталоге;
- все параметры из текста присутствуют в `params`;
- есть `ПЕРВЫЕ N`; если нет — валидатор добавляет `ПЕРВЫЕ 1000`.

Запрос, не прошедший проверку, возвращается модели с описанием причины.

### Шаг 5. Повтор при ошибке

Ошибка 1С или валидатора отправляется модели вместе с исходным запросом. Попыток исправления — две. После второй неудачи бот отвечает, что не смог построить запрос, а всё пишется в лог.

### Шаг 6. Обобщение

Вход: вопрос и результат запроса (не более 50 строк; если больше — первые 50 и пометка об усечении).
Выход: 1–3 предложения с цифрами, суммы с разделителями разрядов и валютой. Пустой результат — ответ «данных за период нет».

## Безопасность

Модель пишет текст, который выполняется в учётной системе, поэтому защита стоит на трёх уровнях:

1. **1С:** сервис работает под отдельным пользователем без прав на данные, запрос выполняется в привилегированном режиме — язык запросов 1С не изменяет данные; число строк результата ограничено (не более 1000).
2. **Python:** валидатор из шага 4.
3. **Telegram:** бот отвечает только пользователям из таблицы `users` с признаком доступа; остальным — сообщение об отсутствии доступа.

Эти три уровня описываются в пояснительной записке как отдельный раздел.

## База данных (PostgreSQL)

| Таблица | Назначение | Основные поля |
| --- | --- | --- |
| `users` | Кто может пользоваться ботом | telegram_id, имя, is_allowed, created_at |
| `request_logs` | История обработки | user_id, вопрос, выбранные таблицы, текст запроса, параметры, статус, ошибка, число попыток, ответ, длительность, created_at |
| `metadata_objects` | Кэш каталога метаданных | полное имя, тип, синоним, схема (JSON), updated_at |
| `settings` | Служебные параметры | ключ, значение |

Каталог метаданных загружается из 1С командой администратора и при первом запуске.

## Сценарии диалога

| Ситуация | Ответ бота |
| --- | --- |
| Понятный вопрос | Ответ с цифрами |
| Значение справочника неоднозначно | Список кандидатов кнопками |
| Вопрос не про данные 1С | Короткое пояснение, что бот умеет, с примерами |
| Запрос не построился за две попытки | Сообщение о неудаче и просьба переформулировать |
| 1С недоступна | Сообщение о недоступности базы |
| Пользователь без доступа | Сообщение об отсутствии доступа |

## Принятые технические решения

- Интеграция — HTTP-сервис в расширении конфигурации: публикация на веб-сервере Apache проверена на учебной платформе 8.3, OData для произвольных отчётных запросов не подходит.
- Вызов модели — OpenAI-совместимый API Yandex Cloud через библиотеку `openai`, модель `yandexgpt-5.1` (проверено по актуальной документации AI Studio).
